pino and pino-pretty

------> Pino is a very fast, low-overhead logging library for Node.js. It outputs logs as structured JSON by default. 

------> pino-pretty is a companion developer tool used to format those raw JSON logs into beautiful, color-coded, human-readable text during local development.

what is express.urlencoded()?
express.urlencoded() is a built-in piece of software (called middleware) in Express. It reads incoming data from an HTML form and converts it into a clean JavaScript object you can use in your code.

what is CORS?
CORS stands for Cross-Origin Resource Sharing. It is a security mechanism built into modern web browsers to protect users from malicious websites.By default, a browser blocks a website from requesting data from a different server unless that server explicitly gives permission.
